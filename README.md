# Service Desk Incident Management and Ticketing Simulation

A spreadsheet-based learning simulation aligned with the resume project description: spreadsheet ticket tracking for desktop, connectivity, application and account-access scenarios, including category, impact, urgency, priority, status, troubleshooting notes, user updates, next actions, triage and escalation.

## Included
- `Service_Desk_Incident_Management_Simulation.xlsx` — Dashboard, Incident Register, Priority Matrix, User Updates, Escalation Tracker and Reference Data.
- `docs/README-usage.md` — workbook usage guide.
- `docs/incident-scenarios.md` — fictional practice cases.
- `docs/manual-validation-checklist.md` — tests to perform and record.

## Scope
This is an educational simulation, not a production ITSM platform. The priority matrix is simplified for practice and is not a universal ITIL or employer policy. All sample names and incidents are fictional. Never enter real employee data, passwords or confidential incident details.

Do not claim manual tests are completed until you perform them and record actual results.
