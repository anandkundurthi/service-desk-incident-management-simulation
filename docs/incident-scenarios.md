# Fictional practice incident scenarios

1. Wi-Fi connection failure: one employee's laptop cannot connect to office wireless.
2. Application startup failure: a business application closes immediately after launch.
3. Printer issue: one user cannot print; other users reportedly can.
4. Repeated Microsoft 365 sign-in prompt: do not ask for or record passwords.
5. Slow workstation: one user reports slow startup and delayed application response.
6. Multiple users cannot access an internal portal: capture scope and escalate according to local process.
7. Software installation request: verify approval and approved deployment method.
8. Keyboard not detected: check safe connections and approved devices.

For each case, record symptoms, intake questions, diagnostic steps, observations, user update, next action and escalation rationale. Do not claim a fix unless you actually tested it.
