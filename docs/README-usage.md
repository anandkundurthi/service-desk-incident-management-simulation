# Workbook usage guide

1. Open the `.xlsx` workbook in Microsoft Excel.
2. Start at Dashboard.
3. Use Incident Register to add and update fictional incidents.
4. Select category, channel, impact, urgency, status and assigned team from dropdowns.
5. Priority is calculated from impact and urgency using the practice matrix.
6. Record communication in User Updates.
7. Record specialist handoffs in Escalation Tracker.
8. Review Reference Data for dropdown values.

For a new incident, enter a date in Date Logged and complete the incident fields. Existing sample tickets are fictional examples.
