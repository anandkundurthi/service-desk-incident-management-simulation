# Manual validation checklist

Record your own actual results and date. Do not mark a test passed until performed.

| Test | Expected result | Actual result / date |
|---|---|---|
| Open workbook | All six sheets visible | Not tested |
| Review dashboard | Counts and chart visible | Not tested |
| Add fictional incident | New row recorded | Not tested |
| Select impact and urgency | Priority formula returns P1–P4 | Not tested |
| Change ticket status | Dashboard count updates after recalculation | Not tested |
| Add user update | Communication recorded | Not tested |
| Add escalation handoff | Handoff recorded | Not tested |
| Use filters | Relevant rows can be filtered | Not tested |

If formulas do not recalculate immediately, enable automatic calculation in Excel.
